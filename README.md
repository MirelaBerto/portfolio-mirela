# Portfólio — Mirela Berto

Bem-vindo(a) ao código-fonte do meu portfólio pessoal construído com **HTML5**, **CSS3 (Modular)** e **JavaScript Moderno**.

## 📁 Estrutura de Pastas

```text
portfolio_mirela/
├── index.html       # Página principal
├── css/
│   └── style.css    # Estilos globais, temas e responsividade
├── js/
│   └── main.js      # Animações, partículas, menu mobile e formulário
└── README.md        # Instruções de uso
```

## 🚀 Como rodar no VS Code

1. Abra a pasta `portfolio_mirela` no **Visual Studio Code**.
2. Certifique-se de ter a extensão **Live Server** instalada no VS Code.
3. Clique com o botão direito em `index.html` e selecione **"Open with Live Server"** (ou clique no botão "Go Live" na barra inferior do VS Code).
4. O site abrirá automaticamente no seu navegador com live reload ativo! ✨
